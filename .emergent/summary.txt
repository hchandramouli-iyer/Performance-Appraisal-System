The user requires a comprehensive Performance Appraisal System to analyze and generate reports on mentee performance. The system must incorporate several data points for evaluation:
1.  **Individual Development Plan (IDP)**
2.  **Rubric**
3.  **Role Level EBR**
4.  **Certifications:** Completed or committed.
5.  **Current and Next Role Fit Analysis.**
6.  **Success Profile:** Based on provided documents for Engineer, Practice Architect, and Team Lead.
7.  **Competency Evaluation:** Ten specific competencies (Ensure Accountability, Cultivates Innovation, Decision Quality, Manages Complexity, Communicates Effectively, Drives Results, Customer Focus, Nimble Learning, Manages Ambiguity, Business Insights), each with a description and five ranking criteria (Excellent to Concerning).
8.  **Project Manager Feedback.**
9.  **Talent Assessment:** Based on provided process and quick reference guides.

**Implementation Details Confirmed:**
*   **AI Integration:** Use Emergent LLM key for report generation and analysis.
*   **User Management:** System for a single manager managing multiple mentees.
*   **Data Storage:** Store all evaluation data in MongoDB and allow on-demand report regeneration.
*   **Report Format:** Provide both PDF export and a web-based detailed view.
*   **Rubric System:** Will be based on predefined formats from uploaded documents.
